# Proxy compatibility

## 中文

VPS Scope 会把“识别到某个产品”和“能够可靠判断风险”分开。表格里的“已识别”不代表已经理解该产品的所有部署方式或数据库版本。

| 工作负载 | 当前覆盖 | 验证方式 |
|---|---|---|

| 3x-ui / x-ui | 版本化原生适配器、面板端口、数据库 schema 探测和动态入口、监听与主机防火墙暴露、生成的 Xray 配置、数据库权限、面板运行态一致性 | Ubuntu 22.04 上的 3x-ui v3.4.2；VLESS Reality、Trojan TLS、Shadowsocks TCP/UDP、VMess WS 已验证；x-ui 变体使用匿名夹具 |

| Docker | 发布地址分类、privileged、host namespace、Docker socket 和宽泛挂载 | Ubuntu 26.04 真实 VPS 上的正常与故意风险容器 |

面板数据库由程序内置的只读 SQLite 读取器访问，不要求目标机安装 `sqlite3`。只执行固定的元数据查询，绝不导出 UUID、密码、私钥、Reality 参数或 TLS BLOB 内容。

测试场景包括：面板管理端口从受限到公网放行、代理 UDP 放行缺失、面板停止后的配置/监听不一致、Docker 回环发布、旧进程仍运行但配置已经损坏、短期 TLS 证书，以及必须确保不会进入报告的假密码和 Token。

提交兼容性问题时，请提供产品版本、安装方式、系统版本、相关服务或容器名称和脱敏报告。不要公开面板数据库或未经脱敏的配置。

VPS Scope separates product detection from security conclusions. A row marked "detected" does not imply that every deployment layout or database version is understood.

Panel databases are read through the program's built-in read-only SQLite reader; the target host does not need `sqlite3`. Only fixed metadata queries run, and UUIDs, passwords, private keys, Reality parameters, and TLS BLOB contents are never exported.

The test matrix deliberately includes panel management moving from restricted to public, missing UDP firewall coverage, a stopped panel with stale configuration, public wildcard listeners blocked by UFW, loopback Docker publication, broken configuration beside a still-running process, short-lived TLS certificates, and secret-bearing fixture values that must never appear in reports.

When reporting an unsupported layout, include the product version, installation method, OS version, relevant service/container names, and a redacted report. Never publish a panel database or unredacted configuration.
